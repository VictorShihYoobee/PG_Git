* Manage customer profiles.
* Maintain currencies.
* Update exchange rates.
* Manage exchange transactions.

 ER Diagram Design 
 
 Customer: Stores details about the individuals performing exchanges.
 
 Currency: Stores available currencies (e.g., USD, EUR, JPY) and their base units.
 
 ExchangeRate: Stores conversion rates relative to a base currency.
 
 Transaction: Records the exchange operations, linking customers, source currencies, target currencies, amounts, and rates.
